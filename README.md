# Metal Slug Lite

一个基于 `HTML5 Canvas + Vanilla JavaScript` 的轻量横版卷轴射击游戏原型，整体风格参考《合金弹头》，强调即开即玩、操作简单、关卡主题明确、便于后续扩展与迁移。

## 项目特点

- 纯前端静态项目，无需安装依赖
- 使用 `Canvas` 实现横版卷轴射击玩法
- 已实现 6 个主题关卡串联闭环
- 包含武器箱、手雷、载具、人质、炮台、Boss、多阶段战斗等内容
- 已加入多关卡中段事件和主题演出，章节差异更明显
- 核心逻辑集中在 `game.js`，方便继续拆分或迁移

## 操作说明

- `A / D` 或方向键左右移动
- `W / ↑ / Space` 跳跃
- `J / F` 射击
- `K / G` 投掷手雷
- `E` 靠近载具时进入或离开载具

## 启动方式

项目是纯静态页面，直接起一个本地 HTTP 服务即可运行。

### 方式一：Python

```bash
cd /workspace
python3 -m http.server 8100 --bind 0.0.0.0
```

启动后在浏览器打开：

- `http://127.0.0.1:8100/`

### 方式二：任意静态服务器

只要能把当前目录作为静态目录托管即可，例如：

```bash
npx serve .
```

## 已实现内容

### 基础系统

- 玩家移动、跳跃、射击
- 手雷投掷与范围伤害
- 平台碰撞与重力
- 相机跟随
- 失败重开与最终通关

### 战斗系统

- 普通枪
- Heavy Machine Gun
- Shotgun
- Flame
- 地面敌兵、狙击兵、机甲、炮台
- 草原关滑翔敌兵

### 关卡系统

- 6 关自动串联
- 清关后继承部分玩家状态
- 每关有独立主题背景和 Boss
- 第 3 到第 6 关已加入中段事件与场景演出

### 主题机制示例

- 冰雪关：冰面惯性、雪痕、冰锥雨、冰墙
- 沙漠关：沙暴、遗迹压板、断墙突刺、遗迹埋伏
- 都市关：广告牌、探照灯、高架列车、导弹雨、能量栅栏
- 草原关：高草遮挡、风车、风刃、荆棘墙、滑翔敌兵
- 海港关：集装箱堆场、吊机摆臂、海面喷溅、深水炸弹、蒸汽柱

## 调试接口

页面内暴露了一个简单调试接口：

- `window.__metalSlugLite`

可用于快速重置关卡或测试流程，例如：

```js
window.__metalSlugLite.resetGame(0);
window.__metalSlugLite.setStage(3);
window.__metalSlugLite.warpPlayer(2400);
```
